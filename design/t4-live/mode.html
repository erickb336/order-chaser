The switch from dry run to live: 3 options

Where does the owner choose a live chase? Each option keeps the live confirm before Start. The options differ in where the choice is and how easy it is to send a live order by mistake. Recommendation: A. It is the form that the owner approved in T2 and T5, so it adds no new screen.

A. Per chase, on the form Recommended

Mode
Live sends real orders to Kraken.
  • The owner chooses for each chase. A dry run is one click away.
  • Live is off (crossed out) until setup is complete.
  • The first time the owner clicks Live, the form shows "What changes" once.
  • The form opens in Dry run each time. (Question Q1.)

Against: a live chase is two clicks from the form (Live, Start) plus the confirm.

Open A on the form

B. Global switch in Setup

Setup, step 4: Live trading
  • One place to turn live on and off.
  • The form has no mode control. The top bar says LIVE or DRY RUN.

Against: a dry run needs a trip to Setup and back. The owner can forget that live is on. It changes the approved form.

C. Two Start buttons

  • No mode to set. The button says what happens.

Against: the two buttons sit side by side, so a mis-click is easy. The form cannot change its text (worst case, fees) before the click. It changes the approved form.
