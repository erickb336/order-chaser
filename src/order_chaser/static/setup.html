3. Kraken API key

Warning: do not turn on Withdraw Funds. The tool refuses a key that can withdraw and removes it from the Keychain.
  1. In Kraken Pro, open Settings, then API, then Create API key.
  2. Turn on Query Funds, Modify Orders, Cancel/Close Orders, Query Open Orders & Trades, Query Closed Orders & Trades and Access WebSockets API.
  3. Leave Withdraw Funds off.
  4. Recommended: set IP whitelisting to the IP address of this Mac.
  5. Save the key. Kraken shows the private key one time only.

4. Safety timer

Warning: if the tool stops during a live chase, Kraken cancels ALL your orders on ALL pairs, also stop-loss and take-profit orders and orders you placed by hand.

During a live chase the tool asks Kraken to cancel all orders in 60 s, and renews that request every 20 s. If the tool crashes, the Mac sleeps or the internet stops, the renewals stop and Kraken cancels the orders. Then no chase order rests without control. Each live chase asks you to confirm it.
